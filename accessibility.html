Nevin Chatbot

Accessibility

The project aims to support keyboard navigation, visible focus indicators, semantic headings, labelled controls, responsive layouts, readable contrast, reduced-motion preferences, and status announcements for assistive technology.

Keyboard use

Use Tab and Shift+Tab to move through controls. Press Enter in the question box to send a question and Shift+Enter to insert a new line.

Response status

The assistant status and conversation use live regions so screen readers can announce important changes.

Report a problem

Accessibility feedback can be submitted through the repository's issue tracker without including sensitive personal information.
