# Nevin Chatbot — AI Math Learning Assistant

Day 2 prototype for the **DDS Building AI Application Challenge 2026**.

## Project goal
Nevin Chatbot is an educational assistant designed to help students understand mathematics through question analysis, concept explanations, and step-by-step solutions rather than only returning final answers.

## Day 2 status
This repository currently contains a static GitHub Pages-ready prototype demonstrating the planned user experience. A small local JavaScript engine supports selected arithmetic expressions and simple linear equations so the interface can be tested without pretending that an LLM/API integration is already complete.

Planned later challenge work includes:
- LLM/API integration
- stronger prompt engineering
- broader mathematics coverage
- accuracy and hallucination evaluation
- safety/validation controls
- deployment and monitoring improvements

## Run locally
Open `index.html` in a browser, or serve the directory with any static file server.
